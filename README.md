## 🌟 Overview

The **Dynamic UI Editor** is a **React-based interactive interface builder** that lets users **customize, preview, and experiment with different UI layouts and visual styles in real time**.  

It’s built with a **furniture-themed aesthetic design**, where users can tweak button styles, shadows, border radii, and preview high-quality images directly — helping developers and designers visualize layouts instantly.

---

## 🚀 Features

- 🎨 **Live Customization Panel** – Adjust UI components in real-time (color, shadows, borders, etc.)
- 🖼️ **Aesthetic Furniture Images** – Replace placeholder boxes with beautiful visuals
- 📱 **Responsive Design** – Toggle between **desktop** and **mobile** layouts instantly
- ⚙️ **Dynamic Configuration** – Data-driven configuration system for all visual settings
- 🌗 **Shadow & Color Options** – Control depth, blur, and color dynamically
- 💾 **Lightweight & Fast** – Powered by React and TailwindCSS, optimized for instant preview

## ⚙️ Installation & Setup

Follow these steps to set up and run the project locally:

1. **Clone this repository**
   ```bash
   git clone https://github.com/yourusername/dynamic-ui-editor.git
   cd dynamic-ui-editor
2. **Install dependencies**
   ```bash
    npm install
3. **Start the development server**
    ```bash
    npm start
       or
    npm run dev
4. **Open in your browser**
```bash
   http://localhost:3000
   (or http://localhost:5173 for Vite)
```

##🧠 How It Works

1. The Config Panel provides sliders, color pickers, and dropdowns to change UI elements dynamically.
2. The Preview Panel instantly renders those updates in real-time.
3. All design choices (colors, shadows, radius, layout) are controlled by a central config object.
4. Layout toggles between desktop and mobile view using a simple layout prop.
